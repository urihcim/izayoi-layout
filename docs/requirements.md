# 十六夜配列 要件

十六夜配列が満たすべきことのまとめ。どう実現するか（実装方式、評価の方法、ツール）は
[設計仕様](design.md) に書く。

各項目の状態は次の 3 つで表す。

- **決定**: 方針として確定している
- **仮**: 評価のために仮に置いている。試した結果で変えてよい
- **未定**: まだ決めていない

最終更新: 2026-10-27

## 1. 目的と進め方

| 項目 | 内容 | 状態 |
| --- | --- | --- |
| 名称 | 十六夜配列 | 決定 |
| 目的 | 自分で使う、効率のよいかな配列を作る | 決定 |
| 進め方 | 配列案をシミュレーションで評価し、問題がなさそうなら実際に使える形にする | 決定 |

## 2. 配列の方式

### 2.1 基本構造

| 項目 | 内容 | 状態 |
| --- | --- | --- |
| 打鍵の方式 | 逐次打鍵のみ。同時打鍵は使わない | 決定 |
| 前置シフト | 月配列系。`D` / `K` を先に押してから次のキーを押すと、シフト面の文字を出す | 決定 |
| 異手シフト | シフトキーと反対の手のキー（`D`＋右手、`K`＋左手）で、通常のシフト面の文字を出す | 決定 |
| 同手シフト | シフトキーと同じ手のキー（`D`＋左手、`K`＋右手）で、原則として濁音・半濁音を出す。濁音・半濁音で埋まらない場所には記号・小書き・句読点を置いてよい（外来音・古語に広げるかは、使ってみた状況で判断する） | 決定 |
| 清音と濁音の位置 | 原則として、濁音・半濁音は対応する文字と同じキーの同手シフトに置く。ば行は は行、ぱ行は ま行、ゔ は う に対応させる（例: か が通常面の `F` なら が は `D`→`F`、か が D 面の `J` なら が は `K`→`J`） | 決定 |
| 単独打鍵 | `D` / `K` を単独で押し、確定系のキー（スペース・Enter など）を続けると句読点を出す。`D` / `K` の直後にかなのキーを続けたときは前置シフトになる | 決定 |
| 使うキー | 31 キー（英字部分の 30 キー＋`'`）。`[` `]` と数字キーは使わず、IME にそのまま渡す（`[` `]` で 「 」 を打てる） | 決定 |
| キーの位置 | US 配列の位置を前提にする | 仮 |
| 面の数 | 通常面（D と K を除く 29 キー）＋ D 面（31 キー）＋ K 面（31 キー） | 仮 |
| シフトキーの連打 | `D`→`D`、`D`→`K` などもシフト面の文字として使える | 仮 |

### 2.2 後置シフト

文字を打った直後にトリガーを打つと、2 文字を別の文字（列）に置き換える。

| 項目 | 内容 | 状態 |
| --- | --- | --- |
| トリガー | 原則として拗音キー（ゃ ゅ ょ）。例外として、それ以外のキーも使ってよい | 決定 |
| 用途 | 外来音、記号、古語（濁音・半濁音には使わない。2.1 の同手シフトで出す） | 決定 |
| 拗音 | 規則を使わず、い段の文字＋小書き（ゃ ゅ ょ）で打つ（き＋ゃ＝きゃ） | 決定 |
| 拗音のシフト省略 | シフト面にある い段の文字は、拗音キーの直前ではシフトを省略して打てる（例: `D`→`;` が に、`;` が ま なら、`;`→ゃ で にゃ）。拗音はどれも 2 打になる | 決定 |
| 後置シフトのシフト省略 | 拗音キーの後置シフトの規則でも、直前の文字がシフト面にあれば、シフトを省略して打てる（例: `D`→`;` が ふ、`;` が れ なら、`;`→ゃ で ふぁ）。シフトを付けて打ってもよい。同じキーの通常面の文字にその拗音キーの規則がある、または い段 のときは省略できない。ふぁ ふぃ ふぇ ふぉ ふゅ は外来音の中でも優先し、シフトを省略して 2 打で打てる配置にする（古語などほかの規則を消して打てるようにはしない） | 決定 |
| 原則の優先順位 | 「濁音・半濁音は同手シフト」と「拗音はい段＋小書き」は例外なく守る。外来音・古語は規則から外れてよく、拗音のシフト省略と重なる規則は無効になる | 決定 |
| 打ったままの並び | 打った並びはなるべくそのまま残す（例: ゔ＋ゅ＝ゔゅ）。規則は、日本語にほぼ現れない並びだけに作る | 決定 |
| 外来音の規則 | ゃ→ァ・ィ、ょ→ェ・ォ、ゅ→ゥ を基本にする。く＋ゃ／ょ→くぁ／くぉ、こ＋ゃ／ょ→くぃ／くぇ、つ＋ゃ／ょ→つぁ／つぉ、と＋ゃ／ょ／ゅ→つぃ／つぇ／とぅ、て＋ゃ／ょ→てぃ／ちぇ、ふ・は＋ゃ／ょ→ふぁ／ふぉ、へ＋ゃ／ょ→ふぃ／ふぇ、お＋ゃ／ょ→うぃ／うぇ、う＋ゃ／ょ→いぇ／うぉ、す＋ゃ／ょ→すぃ／しぇ、ゔ＋ゃ／ょ→ゔぁ／ゔぉ、べ＋ゃ／ょ→ゔぃ／ゔぇ。濁音にも清音と同じ規則を付ける（で＋ゃ→でぃ、ど＋ゃ→づぃ など） | 仮 |
| 記号の規則 | 記号は、かな＋拗音キーで出す（一覧は 2.3）。ゃ は前、ょ は次、ゅ は代替の記号にそろえる（例: か＋ゃ／ょ→← →、っ＋ゃ／ょ→「 」）。げ＋ゃ／ょ／ゅ は小書きの ゃ ょ ゅ だけを出す（規則のある文字の直後に小書きを打つため） | 仮 |
| 記号の規則とシフト省略 | 記号の規則は、後置シフトのシフト省略の対象にしない（シフト面の文字の記号は、同じキーの通常面の文字に規則があるところにだけ置く） | 決定 |
| 古語の規則 | う＋ゅ→ゐ、お＋ゅ→ゑ、く＋ゅ→くゎ（ぐ＋ゅ→ぐゎ） | 仮 |

**注意**: 後置シフトの規則を作ると、規則と同じ並びを文字どおりには打てなくなる。
たとえば「き＋ゃ→ぎ」という規則を作ると「きゃ」が打てない
（青空文庫コーパスで「し＋ょ→じ」とした場合、「しょ」が 15,261 回打てなくなる）。
い段の文字の後に拗音キーを使う規則は作れない。

### 2.3 入力できる文字

| 項目 | 内容 | 状態 |
| --- | --- | --- |
| 清音・撥音 | あ〜ん（ゐ・ゑ・ゎ は対象外） | 仮 |
| 濁音・半濁音 | すべて（ゔ を含む）。前置シフトの同手シフトで出す | 決定 |
| 小書き | ゃ ゅ ょ っ ぁ ぃ ぅ ぇ ぉ ゎ | 仮 |
| い段の位置 | 通常面でもシフト面でもよい。シフト面に置くときは、同じキーの通常面に い段以外の文字があること（拗音のシフト省略のため） | 決定 |
| 長音 | ー | 仮 |
| `'` に置く文字 | `'` には濁音・半濁音と組にならない文字を置く（濁音が K＋`'` になると、`'` に小指を伸ばしたまま同手シフトで打つことになり、打ちにくい） | 決定 |
| 通常面に置く文字 | っ ん ー ゃ ゅ ょ は通常面に置く（「きゃ」などを 2 打で打てるように。ー は外来語を多く含む文章でも打ちやすいように）。す と、頻度の高い文字（青空文庫で 2% 以上の清音・撥音・促音）も通常面に置く | 決定 |
| 約物 | 、 。（`D` / `K` の単独打鍵と D＋`C` / K＋`'`）、？ ！ ゛ ゜ をキーに置く。「 」 は `[` `]`（IME）でも打てる。ほかは後置シフトで出す: っ＋ゃ／ょ／ゅ→「 」 ・、ぺ＋ゃ／ょ／ゅ→『 』 ※、め＋ゃ／ょ／ゅ→【 】 ／、そ＋ゃ／ょ→‥‥ ……（2 文字で出す）、ゎ＋ゃ／ょ→； ’、。＋ゅ→．、、＋ゅ→， | 仮 |
| ほかの記号 | 後置シフトで出す: か＋ゃ／ょ／ゅ→← → ⇒、が＋ゃ／ょ／ゅ→↑ ↓ ⇔、ー＋ゃ／ょ／ゅ→－ ― ～、あ＋ゃ／ょ／ゅ→○ ● ◎、も＋ゃ／ょ→□ ■、ぽ＋ゃ／ょ→◇ ◆、ま＋ゃ／ょ→△ ▲、ぱ＋ゃ／ょ→▽ ▼、い＋ゃ／ょ／ゅ→☆ ★ ×。（ ） 〔 〕 ≦ ≧ ℃ ①〜⑨ などは IME（数字キーや変換）で打つ | 仮 |
| 古語 | ゐ ゑ くゎ ぐゎ を後置シフトで出す | 仮 |
| 句読点の位置 | 、 と 。 は `D` / `K` の単独打鍵で出す | 決定 |

### 2.4 打鍵数の目標

次の文字列を、決められた打鍵数以内で打てるようにする。
濁音・半濁音は前置シフトで 2 打なので、それを含むものは 3 打まで許容する。
外来音・古語の目標は、配置の都合で満たさなくてもよい（拗音・記号の目標は満たす）。
一覧の全体は `config/targets.toml` にある。

| 種類 | 優先度 | 目標 | 例 |
| --- | --- | --- | --- |
| 拗音（清音） | 必須 | 2 打 | きゃ しゅ ちょ にゃ ひゅ みょ りゃ |
| 拗音（濁音・半濁音） | 必須 | 3 打 | ぎゃ じゅ ぢょ びゃ ぴゅ |
| 外来音（清音） | 中 | 2 打 | ファ ティ シェ チェ ウィ ツァ クァ イェ |
| 外来音（濁音） | 中 | 3 打 | ヴァ ヴ ディ ジェ デュ ドゥ グァ |
| 古語 | 低 | 2 打（ぐゎ は 3 打） | くゎ ぐゎ ゐ ゑ |
| 記号 | － | 2 打 | 「 」 …… ‥‥ ？ ！ ・ |
| 記号（追加） | － | 3 打 | 『 』 【 】 ← → ⇒ ○ ● ★ × ～ ※ ； ’ など 35 個 |

## 4. 合格の基準

シミュレーションで「問題なさそう」と判断する基準。

| 項目 | 内容 | 状態 |
| --- | --- | --- |
| 後置シフトの衝突 | 0%（または、衝突する並びを別の方法で打てる） | 仮 |
| 入力できない文字 | 0%（ゕ などの特殊な文字を除く） | 仮 |
| 打鍵数の目標 | 2.4 の拗音と記号の目標をすべて満たす | 決定 |
| 効率 | QWERTY のローマ字入力より、打鍵数と運指の負担が明らかに少ない | 仮 |
| 評価に使う文章 | 普段書く文章に近い傾向の文章で評価する | 決定 |
| その他 | 数値以外に、覚えやすさ・好みで判断する | 未定 |
